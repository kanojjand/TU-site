# Tashenev University — редизайн сайта

Новая версия сайта [Университета имени Ж. А. Ташенева](https://tashenev.edu.kz/ru) (Шымкент). Весь контент русской версии старого сайта перенесён автоматически: страницы, институты, кафедры, руководство и все новости. Дизайн и навигация сделаны заново, по фирменному стилю из официального брендбука.

## Быстрый старт

Нужен Node.js 22.12 или новее.

```bash
npm install
npm run dev        # http://localhost:4321 — разработка
npm run build      # сборка в dist/ + поисковый индекс
npm run preview    # просмотр собранной версии (поиск работает только здесь)
```

## Обновление контента со старого сайта

Контент лежит в `src/data/` (JSON), картинки — в `public/media/` (WebP). Чтобы забрать свежие новости и изменения:

```bash
npm run scrape                      # всё (первый запуск 15–30 минут)
npm run scrape -- --news-limit=40   # только 40 последних новостей, для проверки
```

Сборщик ходит на сервер вежливо (паузы, повторы, замедление при ответе `429`) и кэширует ответы в `.cache/`, поэтому повторный запуск быстрый. После сбора в `src/data/report.json` лежит отчёт: недоступные страницы, битые ссылки, картинки, которые не скачались.

## Структура

```
scripts/scrape.mjs        сборщик контента (страницы, новости, факультеты, кафедры, руководство)
scripts/lib/              HTTP-кэш, очистка HTML, обработка изображений, карта адресов
src/data/                 перенесённый контент (генерируется)
src/config/navigation.ts  структура меню и подвала
src/lib/content.ts        доступ к данным, форматирование дат, адреса
src/components/           шапка, подвал, карточки, галерея, пагинация
src/pages/                страницы: главная, разделы, новости, институты, кафедры, руководство, поиск
src/styles/global.css     дизайн-система: цвета, типографика, сетка, кнопки
public/brand/             логотипы (цветной и белый), знак, превью для соцсетей
```

Адреса совпадают со старым сайтом, только без `/ru`: `/ru/about` → `/about/`, `/ru/media/item/1305` → `/news/1305/`, `/ru/department/9` → `/departments/9/`.

## Публикация

Сборка — обычная статика из папки `dist/`, подходит любой хостинг (Netlify, Vercel, Cloudflare Pages, nginx). Для GitHub Pages в подпапке задайте переменные при сборке:

```bash
SITE_URL=https://<user>.github.io BASE_PATH=/tashenev-site npm run build
```

## Известные ограничения

- Перенесена только русская версия. Казахская и английская собираются тем же сборщиком (структура страниц одинаковая), но нужны переключатель языков и маршруты `/kz/`, `/en/`.
- Фотогалереи новостей (около 6000 фото) не копируются в репозиторий, а загружаются с сервера университета по мере просмотра. Обложки новостей и все остальные изображения сжаты и хранятся локально.
- Ошибки старого сайта перенесены как есть, исправлены только явные опечатки (латинские буквы внутри русских слов). Что стоит проверить редакции:
  - цифры на главной противоречат «Истории» и «Фактам и цифрам»: 61 или 56 программ бакалавриата, 9 или 12 магистратуры, 6 факультетов при 8 в списке;
  - у части новостей даты в будущем или явно ошибочные («0001», «0221») — такие даты не показываются;
  - руководство на странице «Контакты» отличается от страницы «Руководство»;
  - некоторые страницы старого сайта отвечают ошибкой 500 или пустые (список — в `src/data/report.json`).
